Runtime order after the resolver change: declared Oracle Object Storage URLs, other declared HTTP delivery URLs, IPFS gateways, Arweave, then local/development paths. IPFS remains the canonical reference when `ipfsUri` is present; an IPFS-valued `sourceUri` is also treated as canonical for this inventory. `fallbackUris` remains an alternate-location field; the shared resolver applies production delivery priority by URL type. No v3 schema change was needed.

Verification limits: the Oracle host could not be DNS-resolved from this environment (`nodename nor servname provided`), including HEAD checks for the supplied Dystopia model and Cipriani background URLs. No Oracle URL is marked as successfully reachable. Supplied OCI Console bucket screenshots show object names in the `cipriani`, `dystopia`, `lockdowns`, and `wakeupcall` buckets; those filenames are evidence that the objects appear in the listings, but do not verify HTTP reachability. Other URLs are manifest declarations or inferred keys and have no listing evidence in this workspace.
